Every case, scored before you read it.

The Case Review Assistant opens inside the case page, scores the case against your team's five review criteria, and carries the findings into the review template. You stop reading to find problems and start confirming them.

Access is by allow-list. There is no self-service signup. Installing without being on the list gives you a script that loads and then does nothing, with no error explaining why. Ask first; it is one message.

The reading, the checking,
and the retyping.

Scoring is the middle of the job. These are the parts on either side of it.

Case extraction

Reads the case off the page (dates, owners, notes, activity) so nothing has to be copied by hand.

Template auto-fill

Carries the findings into the review template, which is the step that used to be pure retyping.

Bulk review queue

Runs a queue of cases in sequence instead of one at a time, so a review session is one pass, not many.

Phone log diagnose

Shows per-owner timestamps and explains which log it found and why it did or did not count.

Sherlock detection

Flags Sherlock on the case so it is part of the picture rather than something you check separately.

Status templates

Prewritten status text for the common outcomes, so the write-up matches the score you just gave.

Four steps, once.

  1. 1

    Get on the allow-list

    Message odemar@cisco.com with your username and your workgroup. The assistant depends on this; the SLA guard does not, so skip to step 2 if the guard is all you want.

  2. 2

    Install Tampermonkey

    The assistant is a userscript, so it needs a userscript manager. Tampermonkey is what the loader targets.

  3. 3

    Add your tool

    Both downloads are at the foot of this page - take the assistant, the guard, or both. Tampermonkey offers a one-click install on each, and each arrives as a small loader that keeps the real script current, so you install once and never chase a version.

  4. 4

    Open a case

    The launcher appears in the corner of the case page. If it does not, you are probably not on the list yet.

Frequently asked
questions.

  • Which browsers does this work in?

    Anything that runs Tampermonkey: Chrome, Edge, Firefox, Brave, Opera. Both tools are userscripts, so the browser itself is never the thing that has to support them - the userscript manager is. There is no Safari support.

  • I installed it, and nothing appears.

    Nine times out of ten this is a permission the browser withheld rather than anything wrong with the script - and it fails silently, with no error and nothing in the console.

    Chromium browsers - Chrome, Edge, Brave, Opera - run extensions under Manifest V3, which will not let a userscript manager run scripts until you say so explicitly. The switches are off by default. Open your extensions page, find Tampermonkey, open its details, and set:

    • Site access → On all sites
    • Allow User Scripts → on

    Reload the case page. Firefox has no equivalent gate, so there is nothing to change there.

  • It still doesn't appear.

    Check the console on the case page. Every loader prints one line the moment it runs - [CRA Loader] or [SLA Loader] followed by its version and the URL. If you see that line, the loader ran and the problem is downstream, usually the allow-list. If you see nothing at all, the loader never ran, and it is the question above.

  • Do I need to be on the allow-list?

    For the assistant, yes - message odemar@cisco.com with your username and your workgroup. For the SLA Color Guard, no. It works for anyone who installs it.

  • Do I have to reinstall when there's an update?

    No, and that is the point of the two-part design. What you install is a small loader; the real script lives here and the loader fetches it, checks for a newer one about once an hour, and verifies a cryptographic signature before running a single line. A release reaches you without you doing anything.

  • How do I tell which version I'm on?

    The panel carries it: in the header for the Assistant, in the footer for SLA Guard. Click it and the panel shows the release notes for that version and the ones before it. A dot on the version means you were updated and have not read the notes yet; the scripts never go looking for updates themselves, because the loader already fetches the current release for you every hour.

    The current versions are shown in the download section above, filled live from the API rather than typed in by hand.

  • Can I run both at once?

    Yes. They are independent, they do not share state, and they do not collide.

  • Does anything I do get sent anywhere?

    Your review counts and your achievements - the leaderboard needs them and nothing else. No case text, no customer data, no notes: none of that is ever sent to casereview.cc.
