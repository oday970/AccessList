Every case, scored before you read it.

The Case Review Assistant opens inside the case page, scores the case against your team's five review criteria, and carries the findings into the review template. You stop reading to find problems and start confirming them.

Access is by allow-list. There is no self-service signup. Installing without being on the list gives you a script that loads and then does nothing, with no error explaining why. Ask first; it is one message.

split five ways.

It runs on both the case page and the review page, so the workflow stays in one place across both systems.

The reading, the checking,
and the retyping.

Scoring is the middle of the job. These are the parts on either side of it.

Case extraction

Reads the case off the page (dates, owners, notes, activity) so nothing has to be copied by hand.

Template auto-fill

Carries the findings into the review template, which is the step that used to be pure retyping.

Bulk review queue

Runs a queue of cases in sequence instead of one at a time, so a review session is one pass, not many.

Phone log diagnose

Shows per-owner timestamps and explains which log it found and why it did or did not count.

Sherlock detection

Flags Sherlock on the case so it is part of the picture rather than something you check separately.

Status templates

Prewritten status text for the common outcomes, so the write-up matches the score you just gave.

Before you install

The loader is short and readable. If you would rather see what it does before running it, open it first; it is a small file, and it is meant to be read.

Open loader.user.js

Four steps, once.

  1. 1

    Get on the allow-list

    Message odemar@cisco.com with your username and your workgroup. The assistant depends on this; the SLA guard does not, so skip to step 2 if the guard is all you want.

  2. 2

    Install Tampermonkey

    The assistant is a userscript, so it needs a userscript manager. Tampermonkey is what the loader targets.

  3. 3

    Add your tool

    Both downloads are at the foot of this page - take the assistant, the guard, or both. Tampermonkey offers a one-click install on each, and each arrives as a small loader that keeps the real script current, so you install once and never chase a version.

  4. 4

    Open a case

    The launcher appears in the corner of the case page. If it does not, you are probably not on the list yet.
