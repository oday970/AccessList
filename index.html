The scoring model

One hundred points, split five ways.

Not a generic quality checklist. These are the review criteria this team already applies, with a fixed split you can audit and argue with.

25

GCI Freshness

Checks each GCI field against the three-day threshold, and says how stale it is rather than only that it failed.

20

Phone Log

Verifies a phone log was added within three days of ownership, with per-owner timestamps and a diagnose tool.

20

Sentiment

Reads prior reviews to gauge sentiment, and enforces the age > 5 Positive/Negative rule instead of leaving it to memory.

20

Engineer Activity

Measures update cadence across the life of the case, so a quiet stretch is visible without opening the history.

15

Case Age

Scores age against the band, and shows which owner held the case when it crossed.

The panel, on the case page

It opens where you already are.

This is not a separate site you visit. A red launcher sits on the Cisco case page; the panel opens over it, reads the case underneath, and writes its findings into the Estarta review template.

  • Sherlock detection surfaces Sherlock handling, transfers and requeues, with the reasoning behind an escalation.
  • Bulk queue takes a list of SRs pasted from Excel and auto-advances through them.
  • Auto form filler carries every field into the review template, so you verify instead of retype.

Install

Four steps, once.

  1. Get on the allow-list

    Message odemar@cisco.com with your CEC username. Do this first — every later step depends on it.

  2. Install Tampermonkey

    The browser extension that runs userscripts. Chrome, Edge and Firefox are all fine.

  3. Add the loader

    Open loader.user.js and Tampermonkey will offer a one-click install. The loader is version 0.29.0; it keeps the assistant itself up to date after that.

  4. Open a case

    The red launcher appears next to the SR. If it does not, check that step one went through before reinstalling anything.

To remove it: open the Tampermonkey dashboard, find Cisco Case Review Assistant — Loader, and delete it. Nothing is left behind on the case page.
